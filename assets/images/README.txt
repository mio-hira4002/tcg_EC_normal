このフォルダに商品写真を置くと、仮のカード画像が自動で実物写真に切り替わります。

ファイル名：商品ID.jpg（assets/data.js の id と同じ名前。一覧は README.md 参照）
  例）m1.jpg（メガリザードンYex）, m4.jpg（ブラッキーex）, p4.jpg（リザードンVMAX PSA10）
推奨サイズ：縦長 63:88（例：630×880px 以上）、JPG
PSA鑑定品は、カード部分を撮った写真を入れてください（ケースとラベルは画面側で描画されます）。

使える写真：TCG GATEが自店の在庫を撮影したもの、またはメーカー等から利用許諾を得ている素材のみ。
他店サイトや通販サイトの画像は使用しないでください。
